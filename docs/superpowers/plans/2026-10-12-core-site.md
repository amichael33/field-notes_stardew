# Core Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and deploy the read-only core of the Stardew Field Notes site: app shell, beginner path, bundles, gifts and birthdays, and achievements.

**Architecture:** A Vite + React + TypeScript single-page app with hash routing. Game data lives in typed JSON under `src/data/`. Views read it only through pure selector functions in `src/data/selectors.ts`. The Community Center / Joja choice and the season filter live in one React context and are not persisted.

**Tech Stack:** Vite, React 18, TypeScript, react-router-dom (HashRouter), Vitest, @testing-library/react, GitHub Actions + GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-10-12-core-site-design.md`

## Global Constraints

- No backend, no logins, no saving of any kind in this sub-project (route and season choices reset on reload).
- Hash-based routing only, so GitHub Pages needs no server config. Vite `base` is `'./'`.
- Game data is hand-curated JSON transcribed from the Stardew Valley wiki. The README credits the wiki.
- The beginner path is plain-text steps in `path-steps.json`. No structured schedule data.
- Views reach data only through selectors in `src/data/selectors.ts`.
- Print-friendly base CSS: navigation and controls are hidden under `@media print`.
- README includes a non-affiliation notice for Stardew Valley and ConcernedApe.

## Review Focus

1. A season with no matching bundle items (e.g. a filter that matches nothing): shows an empty-state message, not a blank page.
2. Bundle items marked available `any` season: appear under every season filter.
3. Joja route selected: the bundles view explains it is not used on that route instead of rendering or crashing.
4. Unknown hash route (e.g. `#/nope`): redirects to the beginner path instead of rendering nothing.
5. Villager with an empty loves or likes list: renders a "none listed" line without crashing.

**Interfaces:**
- Consumes: `Season` from Task 1.
